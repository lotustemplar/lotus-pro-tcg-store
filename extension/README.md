# Add to Lotus Pro (Chrome extension)
Install: chrome://extensions → Developer mode → Load unpacked → pick this folder (unzip the zip first).
Settings: store URL (preview URL until launch) + the EXTENSION_API_TOKEN from the store's Vercel env.
Use: open a TCGplayer product page → click the icon → check name/qty/price → Add to store.
The store rejects singles (type "Cards"). Re-adding the same product adds to stock (or choose "Set stock to").
